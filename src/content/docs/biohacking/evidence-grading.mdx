# Evidence Grading System

Every protocol on Substrate carries an evidence grade. This is not a popularity score — it's a structured assessment of the underlying literature.

## The grades

| Grade | Standard | Typical sources |
|-------|----------|-----------------|
| **A** | Systematic review / meta-analysis of RCTs / replicated independent verification | Cochrane reviews, large RCT meta-analyses, multiple independent labs reproducing |
| **B** | Single high-quality RCT / large prospective cohort / direct reproduction by us | Pivotal trial (e.g., TACT for EDTA), well-powered cohort (e.g., PREDIMED), our own validated run |
| **C** | Mechanistic plausibility + consistent observational data / strong expert consensus | Mendelian randomization, dose-response in cohorts, guideline statements from major societies |
| **D** | Theoretical / anecdotal / "it worked for me" / animal-only data | Preclinical models, case reports, forum reports, mechanistic speculation without human data |

## How we apply it

A protocol page lists each intervention with its grade:

> **Magnesium glycinate for sleep** — **Grade B**  
> RCT (Abbasi et al. 2012, n=46): 500 mg/day improved ISI by 7.4 points vs placebo. Replicated in open-label extension. Dose: 200–400 mg elemental Mg 30–60 min before bed.

The grade is on the *specific claim at the specific dose*, not the supplement generically.

## What grades *don't* mean

- **A ≠ "safe for everyone"** — safety is a separate axis (contraindications, interactions)
- **D ≠ "doesn't work"** — it means *we don't have reliable evidence it works*. You may still try it (n=1), but you're flying blind.
- Grades can **downgrade** with new evidence (e.g., vitamin E for CVD went from B to D after HOPE/SELECT)

## Transparency

Every graded claim links to:
- PMID / DOI
- Study design, n, population
- Effect size + CI
- Funding source / COI statement

You can audit the grade yourself.

---

*This grading system is inspired by GRADE, Cochrane, and the Evidence-Based Medicine pyramid — adapted for self-experimentation contexts where "wait for Grade A" means never acting.*
